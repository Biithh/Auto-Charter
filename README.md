# Charter

Programa que convierte una canción en un chart para YARG y Clone Hero, hecho con la ayuda de Claude (IA). Lo empecé porque casi nadie chartea música en español y hacerlo a mano es muy tedioso.

**Es una primera versión de prueba.** Los charts tienen errores y lo sigo mejorando. Si lo pruebas, me ayuda mucho que me digas qué parte de la canción está mal y cuál es el problema.

Genera charts en todas las dificultades de:

- Guitarra
- Bajo
- Batería
- Keys
- Pro keys
- Voz (con la letra sincronizada)

Está entrenado con muchos charts y no es perfecto, pero sirve para jugadores casuales o para quien quiera crear charts y busque una base bastante buena desde la que empezar a corregir.

## Requisitos

- Windows 10 u 11
- Una gráfica NVIDIA potente
- Unos 20 GB libres (las librerías y los modelos de IA se descargan al instalar)

Solo lo he probado en este PC:

- Procesador Intel Core i9-14900KF
- Gráfica NVIDIA GeForce RTX 5070 de 12 GB de VRAM
- 32 GB de RAM DDR5

Con este PC, una canción de unos 3 minutos tarda unos 17 minutos. No sé cuál es el mínimo para que funcione: con una gráfica con menos memoria puede ir mucho más lento o no funcionar.

## Instalar y usar

1. Descarga el código (botón verde **Code** → **Download ZIP**) y descomprímelo en una carpeta.
2. Doble clic en `Instalar Charter.bat`. La primera vez tarda bastante, porque lo descarga todo dentro de esa carpeta.
3. Doble clic en `Charter.bat`, arrastra tus canciones a la ventana, elige la carpeta de salida y pulsa **Generar charts**.

Más detalles en [LEEME.txt](LEEME.txt).

Los charts los hace una IA, no una persona. Si compartes alguno, dilo, por respeto a los charters que los hacen a mano. Usa solo canciones que tengas derecho a usar.

## English

Charter turns a song into a chart for YARG and Clone Hero. I built it with the help of Claude (AI), mainly because almost nobody charts Spanish music. **This is an early test version**: the charts have mistakes and I'm still improving it. Feedback is very welcome, especially telling me which part of a song is wrong and what the problem is.

It charts guitar, bass, drums, keys, pro keys and vocals in all difficulties. It's trained on a lot of charts and it isn't perfect, but it works for casual players, or for charters who want a solid starting point to fix up. The interface is in Spanish for now.

It needs Windows, a powerful NVIDIA graphics card and about 20 GB of free space. I've only tested it on one PC: Intel Core i9-14900KF, NVIDIA GeForce RTX 5070 with 12 GB of VRAM and 32 GB of DDR5 RAM. On that PC a song of about 3 minutes takes about 17 minutes. I don't know the minimum it needs: with a graphics card with less memory it may be much slower or not work at all.

To use it, download the ZIP, run `Instalar Charter.bat` once, then open `Charter.bat`. These charts are made by an AI, not by a person, so please say so if you share them, and only use songs you have the right to use.
