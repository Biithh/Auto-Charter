# Charter

Charter turns a song into a chart for YARG and Clone Hero. I built it with the help of Claude (AI), mainly because almost nobody charts Spanish music and charting by hand is really tedious.

**This is an early test version.** The charts have mistakes and I'm still improving it. If you try it, it helps a lot if you tell me which part of the song is wrong and what the problem is.

It makes charts in all difficulties for:

- Guitar
- Bass
- Drums
- Keys
- Pro keys
- Vocals (with synced lyrics)

It's trained on a lot of charts and it isn't perfect, but it works for casual players, or for charters who want a solid starting point to fix up. The interface is in Spanish for now.

## Requirements

- Windows 10 or 11
- A powerful NVIDIA graphics card
- About 20 GB of free space (the libraries and AI models are downloaded during installation)

I've only tested it on this PC:

- Intel Core i9-14900KF processor
- NVIDIA GeForce RTX 5070 graphics card with 12 GB of VRAM
- 32 GB of DDR5 RAM

On this PC, a song of about 3 minutes takes about 17 minutes. I don't know the minimum it needs: with a graphics card with less memory it may be much slower or not work at all.

## Install and use

1. Download the code (green **Code** button → **Download ZIP**) and unzip it into a folder.
2. Double-click `Instalar Charter.bat`. The first time takes a while, because it downloads everything into that folder.
3. Double-click `Charter.bat`, drag your songs into the window, choose the output folder and press **Generar charts**.

More details (in Spanish) in [LEEME.txt](LEEME.txt).

These charts are made by an AI, not by a person. If you share any, please say so, out of respect for the charters who make them by hand. Only use songs you have the right to use.

Genera charts en todas las dificultades de:

- Bajo

- Keys

- Voz (con la letra sincronizada)

Está entrenado con muchos charts y no es perfecto, pero sirve para jugadores casuales o para quien quiera crear charts y busque una base bastante buena desde la que empezar a corregir.
